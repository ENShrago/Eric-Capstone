Project Title & Description: Environmental Data Capstone
I set out to see if there was a reasonable way to identify buildings that could take part in the state of Connecticut's CPACE program in the city of Stamford or the CT Green Bank's Smart-E Loan program.  I also wanted to see if any of those CPACE buildings were in areas needing to address resilience issues as the program has recently been expanded to cover those measures.  I used the adaptive capacity maps produced by the University of Connecticut's Institue for Resilience and Climate Adaptation (CIRCA)'s adaptive capacity maps.  I found most of the buildings with CPACE potential not to be in areas with a great need for resilience, as measured by CIRCA, which was surprising.

  Data - data will have two sub folders, raw data and manipulated data
  outputs - this is where analysis, outputs and visuals created will be stored
